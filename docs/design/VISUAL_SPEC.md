## 1. 气质与参照

- 一张**被烛光照亮的深色橡木桌**，嵌着墨绿毛毡，皮革包边，黄铜钉与铭牌；桌外是昏暗的酒馆，只有桌面被照亮。
- 一切看起来像**真实物件**：卡牌有厚度与投影，金币是真币堆叠，铭牌是蚀刻黄铜，横幅是展开的羊皮纸。
- 氛围词：厚重、温暖、仪式感；不是赌场霓虹，不是卡通。
- 参照：实体桌游夜的桌面摄影；《巫师 3》昆特牌的桌面质感；《Inscryption》的"桌面即舞台"构图（仅借构图，不借画风）。

### 3.1 2.5D 平面

- `.table-viewport`：`perspective: 1600px; perspective-origin: 50% 32%`。
- `.table-plane`：虚拟坐标 **1800 × 1100**（桌面坐标，原点左上），`transform: rotateX(28deg)`，`transform-style: preserve-3d`；按视口 `--scale = min(vw / 1800, vh_available / 1100)` 等比缩放并居中。
- 桌面：橡木桌 1800×1100，毛毡内嵌，皮革包边 26。**桌形随人数**（继承原 3D 舞台）：2–3 人椭圆圆桌；4 人以上圆角方桌（圆角 230 / 毛毡 170）。着色器 `uShape` 切换 SDF，CSS 兜底用 `border-radius`。
- 桌外：酒馆全景照片（Poly Haven `cowboy_town_saloon` CC0，吧台一侧裁图，压暗 + 轻虚化）做天空盒式背景，桌面在前景。
- 卡牌尺寸（平面单位）：**140 × 247**（比例 1250:2208）。对手牌 0.78 倍；本家牌阵 1.0；手牌 1.15 倍并 `rotateX(-28deg)` 立起。
- 平放卡牌有厚度：`::after` 画 4 单位暗边模拟牌边；投影随 Z 高度变化（飞行时投影放大变淡）。

| 6 | (300, 500) · (520, 200) · (900, 120) · (1280, 200) · (1500, 500) |

本家锚点 (900, 800)。每个座位块：黄铜铭牌（名字 + 金币数）→ 绶带（状态）→ 前注槽（面朝下牌或空槽）→ 牌阵行 → **总点数铭牌常显**（牌阵朝桌心一侧末端，结算时放大并打标）；金币堆贴着铭牌，不进牌区。对手块整体 0.78 倍（方桌同一边两席 0.72）。
**方桌边分布**（v1.2）：4 人 左1 上1 右1；5 人 左1 上2 右1；6 人 左2 上1 右2。侧边座位整体旋转 ±90°（卡牌沿桌边竖排），顶边与本家保持正向以便读牌；铭牌、绶带、标签永远正向。
中央：奖池 (900, 470) 金币堆 + 黄铜大数字；牌库 (720, 500)；弃牌 (1080, 500)；偿债池 (1260, 470)，只在非零时显示。

### 3.3 手牌扇面

- 位于平面 y≈1010，围绕圆心 (900, 1900) 扇开，每张夹角 5°，最大跨度 60°；悬停/选中上浮 24 单位并放大 1.06；能力就绪的牌边缘有家族色呼吸光；不可出的牌降饱和 30%。
- 拖动：卡牌跟随指针（屏幕坐标），目标区域（暗置槽 / 牌阵）合法时亮起黄铜描边与脉冲；松手后卡牌飞向目标并"待确认"（半透明、微悬浮），收到回执才完全落地或弹回。
- 键盘：← → 选牌，空格拿起，Enter 放到合法区，Esc 取消；焦点可见。

### 3.4 手机竖屏（≤ 600px 宽）

- 平面改用 **1100 × 1500** 坐标与 `rotateX(22deg)`；对手座位沿顶部弧排布；本家牌阵在中下；手牌扇面压到底部 1/4 高度，牌 1.0 倍。
- 流程轨折成一行滚动；等待行与行动栏合并为底部一条；详视改为底部抽屉。
- 不出现页面级横向滚动；首屏必须看见牌桌与手牌。

### 3.5 枭熊紧凑弹窗（次要，阶段 5）

- 宽 < 520 时等同手机布局；高 < 480 时隐藏流程轨文字只留点阵。

## 4. 进展与等待（核心需求）

- **流程轨**：步骤 = `前注 → 翻注 → 第 1 轮 → 第 2 轮 → 第 3 轮（并列时追加第 4 轮…）→ 结算`，前缀"轮局 N"。完成步打勾（黄铜），当前步发光，未来步暗。能力结算中在当前步下方挂一枚"能力"子标。
- **等待行**：
  - 等别人：`等待 余烬、翡翠 下注…`，被等的座位头像以 1.6 s 周期呼吸；超过 20 s 文案变为 `余烬 还在考虑…` 并出现"拍桌催促"按钮。
  - 等自己：`★ 轮到你 · 把一张牌打到你的牌阵`，整条变为黄铜底，手牌扇面上浮 12 单位，合法区描边脉冲。
  - 系统演出中：`正在翻开前注牌…` / `余烬 正在触发能力…` 带进度细线（有限时长）。
- **座位绶带**：`等待中 / 已下注 / 行动中 / 思考中 / 已出牌`，行动中座位的铭牌点亮黄铜光。
- **阶段横幅**：阶段变更时一条羊皮纸横幅从左扫入、停 1.2 s、向右扫出（共 1.8 s），内容 `第 2 轮 · 余烬 领出`。横幅永不遮住手牌与行动栏。

## 5. 特效规格（显著但有限时长）

| 事件 | 表现 | 时长 |
|---|---|---|
| 发牌 | 牌从牌库弧线飞到各手牌，依次间隔 60 ms，落地轻弹 | 每张 380 ms |
| 下注提交 | 牌飞到暗置槽，落地时一圈黄铜涟漪 | 420 ms |
| 翻注 | 全部暗置牌同时翻面（3D 翻转），最高者升起 + 金色光柱 + 光粒上升；并列时并列者同时升起 | 250 / 360 / 640 ms |
| 付前注 | 每人金币堆飞出金币弧线入奖池，奖池数字滚动 | 470 ms |
| 出牌 | 牌飞到牌阵，落地弹跳 + 投影收拢 | 420 ms |
| 能力触发 | 桌面压暗 → 源牌升起放大到屏幕左 1/3 → 家族色粒子环（火：火星上升 / 潮：涟漪扩散 / 林：叶片旋落 / 秘：符文闪烁 / 冠：金光放射）→ 右侧羊皮纸说明 → 目标座位之间画出光弧 | 进入 500 ms，停留至玩家关闭 |
| 金币转移 | 金币沿弧线飞行带拖尾火星，终点数字滚动 | 600 ms |
| 结算 | 羊皮纸计分板展开，逐张点亮 + 分数飞入总分，胜者行点亮 + 金币雨入其金币堆 | 每步 650 ms |
| 整局结束 | 胜者铭牌放大居中，金币洒落 | 2.5 s |
| 拍桌 | 整桌轻震 + 手掌剪影落下 + 环形冲击波 | 620 ms |

- 所有特效由**公共事件**驱动（`power-sequence.ts` 的 cue 推导），私牌永不进入特效参数。
- 减少动态偏好：卡牌瞬移、横幅淡入淡出、粒子关闭，但**顺序与等待时长不变**。
