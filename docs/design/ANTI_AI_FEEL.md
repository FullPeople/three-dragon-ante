# 去 AI 感 · 判别清单与本项目规则

> 2026-10-03 整理。用户要求：文字提示去 AI 腔；视觉去高光渐变 AI 感；材质朝 Unreal 式真实写照（木 / 石 / 林、法线浮雕）靠拢。
> 来源：网上关于"AI slop / AI 味"的判别文章（见文末），结合本项目实际截图自检。

## 1. 外界公认的"AI 感"信号

视觉：
- 蓝紫 / 紫青渐变，渐变标题文字，渐变主按钮；大面积彩色发光（colored glow / box-shadow）、霓虹描边、玻璃拟态（毛玻璃卡片）。
- 每张卡片都有 1px 灰边 + 大圆角 + 大阴影；三张等宽卡片一排、图标在上两行字在下；左侧 3–4px 彩色竖条。
- 居中大标题 + 标题上方一枚小徽章（pill / badge）；全大写小标签；装饰性 01/02/03 编号；强调色只刷标题里的一个词。
- 默认深色模式 + 中灰正文；对比度不达标；每个按钮都有悬停弹跳 / 放大。
- 字体：Inter / Roboto 万金油，或"有品味的免费字体"套路（Space Grotesk、Instrument Serif、Geist、Fraunces）；衬线斜体只用来点缀一个词。
- 图标：Lucide 全家桶、emoji 当图标、sparkle 星星图标。

文案：
- 口号式、形容词堆砌（"沉浸""极致""优雅"）、营销腔（Elevate / Seamless / Powerful）、泛泛的"开始使用"。
- 手把手的操作提示写成一句完整的温柔句子（"把一张手牌拖到你的暗置区"），而不是一个名词或动词。
- 过多破折号 / 省略号 / 居中的解释性副标题。

根因：模型在没人做决定时取"统计平均"，于是永远是 2022 年 Dribbble 的最大公约数。

## 2. 对照本项目第一版截图的自检（2026-10-03）

命中：黄铜渐变铭牌与按钮、`text-shadow` 发光、"轮到你"条的呼吸发光、合法区域的脉冲光晕、羊皮纸径向渐变面板、首页副标题"在烛光下与巨龙对赌……"、行动栏"拖动或点选一张牌，再点目标区域"、聚光层"点击任意位置继续"。
未命中：紫色系、玻璃拟态、三卡片布局、Inter。

## 3. 本项目规则（从现在起强制）

文案：
1. 提示只用**名词或动词短语**，不写完整句：`暗置` / `出牌` / `选择` / `等待 余烬` / `继续`。
2. 不写口号、不写氛围描写、不写"你可以……"式引导。首页只有标题、设置、按钮。
3. 键盘说明只放在帮助面板，不常驻。
4. 规则解释（能力说明、规则页）保留，因为那是游戏内容，不是 UI 腔；但去掉"点击任意位置继续"之类的提示句，用一个 `继续` 按钮。

视觉：
5. **禁止渐变**（背景、按钮、文字、面板），禁止 `text-shadow` 发光，禁止彩色 `box-shadow` 光晕，禁止毛玻璃。
6. 材质用**照片扫描 PBR**：颜色图 + 法线图 + 粗糙度图；桌面由 WebGL 片元着色器做真实的法线贴图光照（一盏偏上方的定向光 + 一盏暖色点光），不是 CSS 渐变模拟。
7. UI 构件（铭牌、面板、按钮）用**真实材质 + 1px 深色内嵌边**表达体积：木板、皮革、纸张、铁片；边缘用 `inset` 的一亮一暗各 1px 表示倒角，不用大阴影。
8. 强调态用**实色描边或材质切换**（例如合法区域变为亮边 2px 实线、当前座位铭牌换成亮铁），不用发光脉冲；允许 0.3 s 以内的淡入。
9. 阴影只保留**物理阴影**：卡牌落在桌面上的硬边短阴影；面板悬浮时的 1 层短阴影。
10. 字体：中文思源宋 / 思源黑，拉丁 Cinzel；不加字距夸张、不全大写。
11. 图标：自制单色矢量；没有 emoji。
12. 颜色：从材质照片取色；不用纯饱和色；强调色一种（铁锈红或暗金），其余是材质本色。

## 4. 真实材质的做法

- 桌面：`SurfaceGL`（WebGL2）在同一张画布里按圆角矩形 SDF 划分木沿 / 皮革包边 / 毛毡三个区域，各自采样颜色 + 法线 + 粗糙度，统一光照；毛毡用灰底照片乘以墨绿色，边缘加接触阴影（AO）。
- 面板与按钮：CSS `background-image` 直接贴照片纹理（纸、皮革、木），叠一层 1px 内嵌倒角；不叠渐变。
- 卡背：皮革照片 + 平涂单色纹章（两色，无渐变）。
- 没有照片纹理的部位保持纯色，不用程序噪声凑数。
