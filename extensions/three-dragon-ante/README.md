# Three-Dragon Ante · 三龙牌

This is the online multiplayer website and native website-link launcher.
Local bot matches have been removed. Owlbear and Suite entries open the website
in a separate tab and no longer run new games inside Owlbear.
See the [standalone repository README](../../README.md) for current development,
server, testing and compatibility instructions. The original dated documentation
is retained in [docs/HISTORICAL-README.md](../../docs/HISTORICAL-README.md); some
older networking and entry-point descriptions have since changed.
