# PR #1 审查修复

新发布包的独立网站目标为 `3-dragon`，发布脚本将它映射到 `/var/www/dnd-center/3-dragon`。`--website-only` 使用 `canonical-website` 范围；携带经审核的 Suite overlay 时使用 `canonical-with-suite`。旧网站目录继续保留迁移后的启动页和跳转，不会重新写入完整旧网站。

每次发布仍需先读取远端状态并建立新的回滚副本。脚本校验新目录与暂存目录在同一文件系统，再原子切换；跨文件系统时停止。新域名下的其他站点、旧插件目录、Nginx 配置、服务状态和 SQLite 均受保护。历史发布回执仍可回滚历史目标，不能选择新网站；回滚不覆盖发布后新增的牌局数据。

默认 `dist-website/` 构建目录已忽略，可在构建后通过冻结源码检查。公开网站验收脚本使用 `https://dnd.center/3-dragon/` 和同源 API、WebSocket。

邀请复制按钮在连接成功且收到服务端牌桌视图后启用。人数取视图内的座位数，未收到视图时不猜测人数。浏览器回归延迟首个权威视图，检查按钮禁用、收到视图后启用，并验证两人邀请文案。

断线回归允许认证等待期间的有限重试，并从终止性拒绝发生后检查连接次数不再增加。服务端和连接实现未改动。

本轮本地验证：类型检查、默认网站构建、39 项发布保护和回滚检查、完整多人浏览器与断线重连检查通过。检查使用本地浏览器、合成文件系统和 SQLite；不代表远端部署或真实玩家设备验收。后续以本次提交的 GitHub CI 和公开部署证据为准。
