# Runbook · 表现层第三轮纠错（2026-10-03 深夜）

> 用户在本地浏览器试玩后给出十一条纠错。本轮**实质档**（动画系统重做 + 新素材 + 布局）。
> 红线复述：规则引擎 / 协议 / 控制器 / 服务端不动；卡图不动；不用 AI 生成美术；公共投影永不含私牌；提交 ≠ 接受；bundle 零外部请求；新素材只从用户已批准的 CC0 来源（Poly Haven / ambientCG / Kenney）下载并登记，其它来源先请示；push 需用户确认。

## 1. 十一条纠错 → 查证结论

| # | 用户纠错 | 代码里查到的现状 | 裁决 |
|---|---|---|---|
| 1 | 金币移动没有动画 | 金币弧线是特效画布上 11 px 的径向渐变小圆点，620 ms，与黄铜铭牌同色，几乎不可见；金币堆（DOM）本身不动 | 成立。改为 DOM 金币精灵（真实硬币图）逐枚沿弧线飞行、落入堆中弹一下，堆的数量随落地增加 |
| 2 | 能力选项界面在打出牌的瞬间就弹出；应该是落地 → 特效射向触发方 → 选项界面（特效持续）→ 选完收尾 | `ChoicePanel` 只在 `show.power/score/formation/tally` 时隐藏，落地停顿（SETTLE）期间 `show` 为空、面板就出现；特效播完即消失，没有"持续"态与"收尾" | 成立。面板在 `busy` 期间隐藏；presenter 在能力需要某家选择时进入 `powerHold`（目标区持续特效 + 标签），选择结算的下一帧播收尾 |
| 3 | 奖池金币偏移；金币堆太薄、旋转太乱 | `.tda-stakes` 是 flex 列，`.tda-coins` 绝对定位在 (0,0) → 堆在盒子左上角；每枚随机旋转 0–360°、无厚度 | 成立。奖池 / 偿债池改为"铭牌在上、金币锚点在下"；金币改为小角度（±5°）抖动、每枚带 3 px 厚边、最多 4 列 |
| 4 | 不同人数下区域互相重合（含弃牌堆） | 锚点凭手调，没有任何重叠检查 | 成立。写布局检查（所有座位区 + 中央牌堆的包围盒，2–6 人 × 横竖屏）进自测，按报告调锚点 |
| 5 | 天空盒透视像凹进去的球 | 直接裁了等距柱状全景的一段，边缘有球面弯曲 | 成立。用针孔相机模型把全景重投影为直线透视（横 92° / 竖 68° 视场，略俯视） |
| 6 | 各家手牌与点数标签按座位角度旋转，不要统一朝向玩家 | 侧边座位旋转 ±90°，顶边与圆桌对手仍为 0°；点数铭牌、组合标签永远正向 | 成立。座位朝向统一为 `atan2` 指向桌心（顶边 180°，圆桌对手按位置角），手牌背 / 前注 / 牌阵 / 点数铭牌 / 组合标签 / 场地环随之旋转；姓名铭牌与状态绶带保持正向（UI 铭牌） |
| 7 | 所有特效不满意：手诡异、法阵太扁、龙祭司星星遮数字；不要程序化特效，用现成美观资源 | 全部是 canvas 画的几何图元；万能 / 骑手标记是卡面左上角的 ★ / ⚑ | 成立。换 Kenney Particle Pack（CC0，已批准来源）的软粒子贴图做烟 / 火 / 光 / 魔法 / 星 / 划痕；法阵改 0.78 透视 + 光柱；标记移到卡外小徽章。**手掌需要真实照片素材**，Kenney 没有 → 请示来源 |
| 8 | 偷牌 / 抽牌从牌库中间播；偷牌要"伸出 → 抖动 → 飞走 + 旋转"；抽牌逐张从牌库飘起飞过去；白龙被收钱者无特效 | 进手牌一律 `arriving`（从扇面下方升起）；对手手牌只是数量变化；没有"幽灵牌"飞行系统 | 成立。新增 transfer 幽灵牌系统：按公共事件（CARD_TRANSFERRED / 随机取牌 / 抽牌 / DISCARD_RECLAIMED）逐张飞行，被偷的牌背先前伸抖动；付款方有收款特效 |
| 9 | 前注阶段排版突变（高度变了又变回） | `.tda-status` 只有 min-height，等待行文字换行时整行变高，牌桌区域随之缩放 | 成立。状态行与等待行定高、不换行（本轮已改） |
| 10 | 放牌要炉石感：飞到目标上空对齐 → 停一下 → 加速落下；别人的牌先反面、落下过程中翻正 | 现在是"抬起 → 直接落到目标" | 成立。CardNode 阶段改为 fly（到目标上空，对手牌反面）→ hover（180 ms）→ drop（翻正 + 加速落下） |
| 11 | 拍桌的手要成熟动画；允许连拍（手在桌上时再拍是另一种动作）；各家独立 | canvas 画的手；每次调用一个独立效果，但同一位置重叠；无"手还在桌上"状态 | 成立。每个座位一台手状态机（off → slam → rest → re-slam / lift），精灵待素材 |

## 2. 方案与顺序

- **R3-A** 状态行定高（#9）；天空盒重投影（#5）；Kenney 粒子包下载登记（#7 素材）。
- **R3-B** 金币：DOM 精灵飞行 + 堆重做 + 奖池锚点（#1、#3）。
- **R3-C** 座位朝向通用旋转 + 布局重叠检查进自测 + 锚点调优（#4、#6）。
- **R3-D** 选择面板时序与 powerHold / 收尾（#2）。
- **R3-E** 放牌三段（#10）；幽灵牌转移系统（#8）；标记徽章（#7）。
- **R3-F** 精灵粒子渲染器 + 每族脚本重调 + 法阵 + 场地层（#7）；拍桌状态机（#11，精灵待批）。
- **R3-G** 测试、截图、留痕、独立审计。
